# Mohamed Aden

IT graduate from Hargeisa, Somaliland. I'm learning frontend development, and I want to build useful products that bring AI and good design together.

## What I'm building

**Macallin**, a tutoring app for Somaliland. Finding a good tutor here often depends on who you know, so I'm building a place where students and teachers can find each other. It's written in Flutter.
[View the repo](https://github.com/mohamedaadam07-commits/macallin_app)
